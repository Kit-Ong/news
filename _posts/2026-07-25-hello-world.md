Welcome to my blog! This is the first post on this site.

## What is this?

This is a personal blog built with [Jekyll](https://jekyllrb.com/) and hosted on
[GitHub Pages](https://pages.github.com/). Posts are written in Markdown and can be
created directly from GitHub Issues or Pull Requests.

## How to publish a post

Open a new Issue (or Pull Request) in the
[Kit-Ong/news](https://github.com/Kit-Ong/news) repository and add the **`blog`** label.
A GitHub Actions workflow will automatically convert it into a blog post and publish it here.

Stay tuned for more posts!
