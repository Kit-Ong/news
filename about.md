  <h1>About</h1>

  <p>
    Hi, I'm <strong>Kit-Ong</strong>. This is my personal blog where I write about
    things I find interesting — projects, ideas, and whatever I'm working on.
  </p>

  <p>
    You can find me on <a href="https://github.com/Kit-Ong" target="_blank" rel="noopener">GitHub</a>.
  </p>

  <h2>How posts are published</h2>

  <p>
    Blog posts are created automatically from GitHub Issues labeled
    <strong><code>blog</code></strong> in the
    <a href="https://github.com/Kit-Ong/news" target="_blank" rel="noopener">Kit-Ong/news</a>
    repository. When a new issue with that label is opened (or labeled), a GitHub
    Actions workflow converts it into a Jekyll post and publishes it here.
  </p>

  <p>
    Pull requests labeled <strong><code>blog</code></strong> are handled the same way —
    the PR title and description become a blog post.
  </p>
